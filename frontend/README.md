# Frontend (Role 1)

React + Vite + Tailwind Video Conferencing UI with Live Multilingual Subtitles & Audio Playback.
Implements Sections A4 and B1 of `shared/CONTRACT.md`.

## Running the Frontend

```bash
# 1. Install dependencies
npm install

# 2. Run Vite dev server (port 5173)
npm run dev
```

Connects to Call Server on `ws://localhost:8000`.
